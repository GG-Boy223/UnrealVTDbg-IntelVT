# ApcInject 拆分报告

**更新日期:** 2026-06-12

## 拆分概览

`ApcInject` 已从单体实现拆为 `Api/`、`Core/`、`Types/` 三类目录。当前实现是 x64-only 注入链，旧的 32 位 shellcode 和跨架构注入说明已经废弃。

```text
Common/Ring0/Inject/ApcInject/
├── ApcInject.cpp
├── ApcInject.h
├── Api/
├── Core/
└── Types/
```

## 模块职责

- `Api/`：导出给调用方和内核内部使用的 API 声明。
- `Types/`：PEB、API Set、native support、system information 等结构声明。
- `Core/ApcQueue.cpp`：APC 注入入口、APC 入队、回调和 WOW64 目标拒绝。
- `Core/ThreadLookup.cpp`：目标线程筛选。
- `Core/ShellcodeBuilder.cpp`：x64 shellcode 生成。
- `Core/UserModuleLookup.cpp`：用户模块查找。
- `Core/ApiSetResolver.cpp`：API Set 解析。
- `Core/ImagePathResolver.cpp`：镜像路径解析，x64-only 路径固定 System32。
- `Core/SxsResolver.cpp`：SxS 解析，WOW64 目标直接拒绝。
- `Core/ExportResolver.cpp`：PE64 导出解析。
- `Core/RemoteRoutineCall.cpp`：远程例程调用，WOW64 目标直接拒绝。
- `Core/StringUtilities.cpp`、`Core/KernelResolver.cpp`、`Core/ThreadExecution.cpp`、`Core/UtilityFunctions.cpp`：通用工具、内核基址、SSDT、模式搜索和线程执行。

## x64-only 规则

- WOW64 目标只用于拒绝 gate，不再进入注入流程。
- Shellcode 生成只保留 x64 版本。
- 模块路径不再解析 32 位系统目录。
- PE 解析只接受 PE64。
- 入口函数、线程查找、远程调用、SxS 解析都要在发现 WOW64 目标时返回明确失败。
